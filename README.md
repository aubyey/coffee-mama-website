#  Coffee Mama - Local Coffee Shop Website

A responsive static website designed for **Coffee Mama**, a local coffee shop based in Tarlac. Built to highlight featured beverages, showcase brand identity, and provide customer contact details.

## Features
- **Responsive Layout:** Optimized for mobile, tablet, and desktop screens.
- **Menu & Offerings:** Displays signature drinks and specials with clean visual cards.
- **Location & Hours:** Easy-to-find operating hours and store location for visitors.
- **Interactive UI:** Smooth navigation, hover effects, and mobile drawer menu.

## Tech Stack
- **HTML5** – Semantic markup and page structure
- **CSS3** – Layout styling, flexbox/grid, and media queries
- **JavaScript** – Responsive navigation toggles and dynamic UI effects
